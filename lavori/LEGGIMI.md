# lavori

Qui gli agenti salvano quello che finiscono: pagine web, immagini, video,
audio, PDF, documenti.

Quando un agente chiama `pubblica_risultato`, il mondo apre il file da solo
nella **Vetrina** — una pagina si sfoglia, un video parte, un audio si ascolta.

È l'**unica** cartella che il mondo accetta di mostrare. Una consegna che punta
altrove viene rifiutata, così un agente non può pubblicare per sbaglio un file
privato che sta da un'altra parte sul tuo computer.

Il contenuto resta sul tuo computer: non finisce nel repository.
